========================================================
 COMO RENOVAR O TOKEN DO DROPBOX QUANDO EXPIRAR
========================================================

Quando o comando de automacao der erro "expired_access_token":

--------------------------------------------------------
 PASSO 1 - Gerar token novo no Dropbox
--------------------------------------------------------
1. Acesse https://www.dropbox.com/developers/apps
2. Abra o app "conector_ofi7"
3. Aba Permissions, marque:
   - files.metadata.read
   - files.content.read
   - files.content.write
4. Aba Settings -> OAuth 2 -> Generate access token (ou Regenerate)
5. Copie o token inteiro (comeca com "sl.")

--------------------------------------------------------
 PASSO 2 - Colar no PythonAnywhere (1 linha so)
--------------------------------------------------------
Abra um Bash Console no PythonAnywhere e cole isto,
trocando SEU_TOKEN_NOVO pelo que voce copiou (entre aspas):

/home/ofi7ipojuca/.virtualenvs/venv/bin/python /home/ofi7ipojuca/ofi7/manage.py update_dropbox_token "SEU_TOKEN_NOVO"

PRONTO. O comando salva no arquivo seguro, aplica permissao
e JA TESTA a conexao com o Dropbox automaticamente.

--------------------------------------------------------
 SE VOCE QUISER APENAS SALVAR SEM TESTAR
--------------------------------------------------------
Acrescente --no-test no final:

/home/ofi7ipojuca/.virtualenvs/venv/bin/python /home/ofi7ipojuca/ofi7/manage.py update_dropbox_token "SEU_TOKEN_NOVO" --no-test

--------------------------------------------------------
 CAMINHO DOS ARQUIVOS (se precisar de apoio)
--------------------------------------------------------
- Arquivo seguro com token: /home/ofi7ipojuca/.secrets/oficina_env.sh
- Comando sync:            manage.py sync_cilia_dropbox
- Comando atualizar token: manage.py update_dropbox_token "NOVO"
- Tarefa agendada (Tasks): bash -lc 'cd /home/ofi7ipojuca/ofi7 && source /home/ofi7ipojuca/.secrets/oficina_env.sh && /home/ofi7ipojuca/.virtualenvs/venv/bin/python manage.py sync_cilia_dropbox'
